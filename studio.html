How editing works

  • Click text to edit it. Use the toolbar for bold, italic, links, headings and bullet lists.
  • Hover a block to move it (drag the handle or use the arrows), add a new one below, duplicate it or delete it.
  • Press Ctrl+S (Cmd+S on Mac) or Publish to make changes live. Discard throws away unpublished edits.
  • Restore original brings back the text that ships with the code. Your edits stay in History.
  • Pasted text arrives as plain text, and anything unsafe (scripts, embeds, images) is removed automatically.
